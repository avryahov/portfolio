Премия Digital Awards РБК Петербург

Проект «Мониторинг качества воздуха» для платформы «Город Онлайн» стал победителем премии. Проект создавался для повышения качества жизни людей в удаленных регионах России на примере малых городов Мурманской области.

Финалист премии

Второй проект раздела стал финалистом премии: совместная разработка с партнерами из компании «Аладдин», направленная на защиту IT-инфраструктуры.

Лизинговый калькулятор (2021–2022) Backend-модули расчета, безопасность, документация API, контур отчетности. PKI импортозамещение (2022–2023) Legacy + микросервисная эволюция, X.509/OCSP/CRL, сертификационный контур. B2B ритейл-портал (2023–2025) Модули тарифов и артикулов, рост до техлида, процессы команды 4–5 человек. Экология и мобильная интеграция (2023) «Город Онлайн»: мониторинг воздуха для Никеля, Мончегорска, Заполярного и Норильска; public real-time витрина данных, в новом срезе (февраль 2026) по Мончегорску индекс «1 — Отличное».
