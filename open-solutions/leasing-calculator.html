Лизинговый калькулятор

Backend-разработка модулей финансового расчета и документооборота в корпоративном лизинговом контуре.

Расчетный backend + документарный поток + интеграции

Проект требовал точности формул, предсказуемости API и устойчивого прохождения данных между расчетными и пользовательскими сценариями.

Java 8/11платформа разработки
Spring BootMVC/Data/WebFlux/AOP
PostgreSQLрасчетные данные
JWTконтур безопасности

Роль в проекте

Junior/Middle Backend. Реализация расчетных сервисов, интеграция внешних курсов и поддержка формульных контуров.

Фокус ответственности

Корректность вычислений, документация API, качество тестов и устойчивость регламентов для бизнес-пользователей.

Контекст проекта

Клиент — крупная логистическая компания международного уровня; стартовая роль Junior Java Developer с ростом до Middle в течение проекта.

Что делал

  • REST API: проектирование эндпоинтов, версионирование, документирование через Swagger/OpenAPI.
  • Микросервисы: самостоятельная реализация ключевых сервисов под сопровождением архитектора.
  • Сервис синхронизации курса валют ЦБ: WebClient, XML-парсинг, хранение метаданных.
  • Сервисы отчетов: Thymeleaf, конвертация документов, выгрузка через Apache POI.
  • Валидация данных: JsonSchema + бизнес-правила.

Безопасность и архитектура

  • Самостоятельная интеграция Spring Security + JWT в рамках спринта.
  • Защита эндпоинтов по ролям, обработка срока действия токенов.
  • Освоение слоев микросервисной архитектуры: контроллеры, сервисы, DAO.

Инструменты команды

  • Jira, GitLab CI, merge request-процесс.
  • Первый опыт взаимодействия с фронтендом и DevOps.
  • Sentry, AOP-логирование, Logback-практики.

Результат

Быстрый переход к самостоятельной реализации сложных backend-задач и подготовка к следующему технологически тяжелому PKI-проекту.
