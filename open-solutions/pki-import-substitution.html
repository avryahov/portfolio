PKI-проект корпоративного центра сертификации (NDA)

Наименование и заказчик не раскрываются. Ниже описан технический контур и инженерные задачи без идентифицирующих деталей.

Certificate Authority / Registration Authority / validation services

Стабилизация и развитие отечественного PKI-контура: legacy-поддержка, миграция на современный стек и поддержка сертификационных процессов.

Java 7/8/11/17 Java EE + Spring Boot X.509 / OCSP / CRL PostgreSQL Bash automation Cross-platform testing

Роль и зона ответственности

Middle Backend: работа с legacy-слоем, декомпозиция задач, проектирование API и участие в производственном контуре качества.

Сложность домена

Криптография, валидация сертификатов, высокая цена ошибок и необходимость совместимости с существующей инфраструктурой.

Финалист премии

Проект в партнерстве с компанией «Аладдин» вошел в число финалистов Digital Awards РБК Петербург.

Контекст

Импортозамещение Microsoft CA-класса в рамках госпрограммы: сертификационные требования, высокий порог надежности, архитектурная эволюция от legacy к микросервисам.

Legacy и криптодомен

  • Глубокий анализ EJBCA-кода и тестов для восстановления бизнес-правил.
  • Интеграция сервисов OCSP/CRL и центра сертификации.
  • Работа с X.509, шаблонами сертификатов, ключевыми носителями и HSM-контуром.

Архитектура и функции

  • Логические сегменты: корпоративный ЦС, каталог, центр регистрации, валидация, выпускающий ЦС.
  • Поддержка алгоритмов (RSA/ECDSA/ГОСТ), REST API и ролевая модель доступа.
  • Интеграции с доменными каталогами и multitenancy-сценарии.

Инфраструктура и CI/CD

  • Linux-диагностика, openssl-проверки, развертывание стендов в Proxmox.
  • Тестирование под Astra Linux, РЕД ОС, ALT Linux.
  • Интеграция двух CI/CD-контуров: GitLab CI и Jenkins, сборка EAR/WAR через Maven и bash-скрипты.

Миграция и лидерство

  • Декомпозиция монолита на микросервисы, версионирование API, Liquibase, NGINX, OpenFeign.
  • Первый практический опыт техлидства: координация backend/frontend/devops и принятие решений по рефакторингу.

Итог и переход

Сертификационный и миграционный контур завершен; после выхода проекта на плато выполнен переход на новый продуктовый вызов в ритейл-проекте.

Формулировки выверены с учетом NDA: сохранена техническая глубина, но исключены названия и данные, позволяющие идентифицировать конкретного заказчика.
