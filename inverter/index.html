Май 2018 — Июль 2021

АО «Завод «Инертор»

Java-разработчик и инженер промышленного мониторинга

Работал в промышленном контуре с высокой ценой ошибки, на стыке ПО, оборудования и эксплуатационных ограничений площадок.

Развивал Swing/Android/C-решения, внедрял Modbus-интеграции, усиливал инженерные процессы и автоматизацию в рабочем цикле отдела.

Довел ключевые решения до промышленных релизов для критической инфраструктуры и повысил надежность эксплуатационного контура.

2018 · Вход в промышленный контур

Java Swing-приложения для мониторинга и сопровождения производственных процессов.

2019 · Android-реплика

Мобильный дублер мониторинга для оперативной инженерной диагностики.

2019–2020 · Промышленные протоколы

Modbus RTU/TCP и сопряжение с оборудованием в условиях реальных ограничений площадки.

2020–2021 · Эксплуатационные процессы

Скрипты автоматизации, поддержка инфраструктуры, внедрение SVN/Redmine.

Контекст работы

  • Трудоустройство в лабораторию технического отдела после периода преподавания.
  • Производство систем бесперебойного питания и проектов для критической инфраструктуры.
  • Переход в промышленный инженерный контур с высоким уровнем ответственности.

Испытательный срок: Modbus-эмулятор (JavaFX)

  • Изучение Modbus с нуля (RTU/TCP, адресация, форматы кадров).
  • Реализация эмулятора устройства и драйвера под реальное оборудование.
  • JavaFX-интерфейс с логом обмена пакетами.
  • Результат: успешный проект и перевод в штат.

Основная система мониторинга (Swing + Modbus)

  • Форк и глубокая переработка desktop-решения на Swing.
  • Декларативная XML-конфигурация: сигналы, подключения, мнемосхемы, табы/окна.
  • Эксплуатация на Linux HMI-панелях, офлайн-деплой, профилирование через VisualVM.

Android-реплика и C-контур

  • Перенос части функционала в Android Java для мобильного мониторинга по Modbus TCP.
  • Система на чистом C для ICP DAS: работа с проприетарными библиотеками и графикой 800×480.
  • Ручное управление таймингами, счетчиками обновления и опросом контроллеров.

Предметная и инженерная глубина

  • Чтение схемотехники, даташитов, анализ прошивок STM32 для понимания регистровой модели.
  • Погружение в электронику: трансформаторы, байпасы, аккумуляторы, архитектура СПБ/ИБП.
  • Работа со шлюзами, SMTP-конвертерами, DOS-контуром и протокольной интеграцией на площадке.

Проект ЩПТ для АЭС и командировка

  • Разработка итерации системы для комплексов 7–11 шкафов с агрегацией в единую точку отображения.
  • Доведение до промышленного релиза и отправка опытного образца на АЭС.
  • Командировка на объект со строгим режимом безопасности и изолированной средой без интернета.

SVN и Redmine: внедрение процессов

  • Внедрение централизованного SVN-контура для инженерной документации.
  • Автоматизация резервного копирования и восстановление сервера после падений.
  • Установка/кастомизация Redmine (Ruby/Rails), обучение персонала, инструкции и митапы.
